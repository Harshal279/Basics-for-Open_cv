<h2>📥 Getting Started</h2>

<h3>Installation</h3>
<p>To start using OpenCV, you need to install it via pip. Run the following command:</p>
<pre><code>pip install opencv-python</code></pre>

<h3>⚠️ Note for Google Colab Users</h3>
<p>If you are using Google Colab, replace <code>cv2.imshow()</code> with:</p>
<pre><code>from google.colab.patches import cv2_imshow</code></pre>
